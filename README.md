## Description du projet
Voici mon rendu pour l'évaluation finale de JavaScript. C'est une application de To-Do List assez simple qui permet de noter ses tâches, de les cocher quand elles sont finies, ou de les supprimer de la liste. Le tout a été codé en pur HTML/CSS et JS, sans framework.

## Ce qui a été fait (Fonctionnalités terminées)
J'ai pu faire toutes les consignes de base, ainsi que lesbonus :
- L'interface HTML et le design CSS (avec la page bien centrée).
- L'ajout d'une tâche (avec l'affichage d'un message d'erreur si on valide à vide).
- Le bouton pour barrer une tâche quand elle est terminée.
- Le bouton pour supprimer définitivement une tâche (en utilisant la méthode splice).
- Le compteur dynamique qui calcule les tâches encore en cours.
- **Bonus 1 :** Les filtres (Toutes / En cours / Terminées) avec la méthode filter().
- **Bonus 2 :** La sauvegarde avec localStorage pour retrouver ses tâches quand on actualise la page.
